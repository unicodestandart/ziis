# ЗИИС — зооморфная искусственная интеллектуальная система

Программная реализация архитектуры В. А. Сычёва: детерминированная
событийно-временная сеть спайковых конечных автоматов на базе функциональных
искусственных мемстинктов (ФИМ).

**Чего в проекте принципиально нет:** матричного умножения, весов с плавающей
точкой, функций потерь, градиентного спуска и статистической аппроксимации.
Только целые миллисекунды, булевы флаги и дискретные состояния синапсов.
Запрет проверяется тестом `tests/test_purity.py`.

## Запуск

Нужен только Python 3.10+ (стандартная библиотека, внешних зависимостей нет).

```bash
python -m ziis demo --text "мама мыла раму" --levels 9
python -m ziis selftest
```

`demo` пропускает текст через буфер клавиатуры, ждёт консолидации, печатает
запомненные паттерны по уровням, затем предъявляет текст повторно
и воспроизводит память нисходящей волной.

Для точной сборки слов и фраз задайте предустановленные слоги и одну
группу ФИМ: верхние уровни будут учиться на канонических слогах, а не на
перекрывающихся парах вроде «ам» из «мама».

```bash
python -m ziis demo --levels 3 --epochs 10 --groups 1 \
  --bootstrap "ма,мы,ла,ра,му"
```

С этим набором уровень 2 собирает «мама», «мыла», «раму», а уровень 3 —
всю фразу «мама мыла раму».

## Структура

```
ziis/config.py     временные и топологические константы (только int)
ziis/clock.py      очередь событий (время, порядок постановки)
ziis/links.py      синапсы: односторонний, вспомогательный, «верх/низ»
ziis/neurons.py    автоматы Element, BasicNeuron, HeadNeuron
ziis/fim.py        кольцевой осциллятор H -> B1 -> B2 -> B3 -> B4 -> H и уровень
ziis/instinct.py   инстинкт внимания «В», реципрокная пара «С»/«Ц»
ziis/motor.py      волевой шлюз и моторные элементы
ziis/system.py     сеть, входной буфер, запоминание/узнавание/воспроизведение
ziis/__main__.py   текстовый стенд
tests/             45 тестов: тайминги, захват, консолидация, узнавание, вывод, обучение
docs/ARCHITECTURE.md  разбор принятых решений и отступлений от ТЗ
```

## Как это работает в двух абзацах

Каждый ФИМ — кольцо из головного нейрона `H` и четырёх базовых `B1..B4`.
Инстинкт внимания, получив три буквы за 300 мс, тактирует головные нейроны
каждые 250 мс. Бегущей волны с задержкой на синапс нет: такт открывает базовым окно
экспозиции, и слоты заполняются строго по порядку — `B1` берёт первый
пришедший сигнал, `B2` только следующий, пришедший позже, и так до `B4`.
Координат текста в этой логике нет: значение имеет только порядок спайков. Поэтому «м», «а», «м», «а» дают слог `ма` и слово `мама`,
а не набор букв из разных мест текста. Цепочка, захваченная один раз, — ещё
не память: на нижних уровнях она становится ею, только если подтвердилась
в другом цикле консолидации (`min_support`), поэтому первая, случайная эпоха
ничего не замораживает, а долгое обучение сходится к тому, что в тексте
действительно повторяется. Предустановленные слоги задают словарь, на
котором слово собирается целиком, а не из перекрывающихся пар. Верхние уровни видят фразу редко, и им хватает
одного подтверждённого кадра: иначе длинная последовательность не записалась
бы никогда.
При фиксации три вспомогательных спайка навсегда переводят захваченные
связи из `STATE_1` в `STATE_2_PERM`, и паттерн сразу уходит наверх.

Узнавание идёт снизу и по порядку: спайк по постоянному синапсу сдвигает
курсор ФИМ на следующий слот, а нейрон без закреплённых связей пропускается
насквозь — память из двух элементов узнаётся так же, как из четырёх. Спайк,
дошедший до `H`, — это и есть узнавание, и он же уходит на уровень выше:
уровень 2 собирает слоги в слова, уровень 3 — слова во фразы. Команда
«два спайка подряд от Инстинкта» открывает базовым нейронам разрешение на
выдачу: сигналы уходят вниз строго в том порядке, в котором были записаны.

## Что проверено тестами

* тактирование входа строго по 100 мс независимо от скорости набора;
* символы шума (`#`, `@`, `&`) не запускают запись памяти;
* каждый базовый нейрон записывает свой порядковый элемент, «затвор»
  не даёт перезаписать его следующим символом;
* консолидация при двух разных базовых нейронах, отсутствие фиксации при одном;
* переходы `STATE_1 -> STATE_2_TEMP -> STATE_2_PERM`;
* узнавание знакомой последовательности и отсутствие реакции на чужую;
* сходимость обучения с предустановленными слогами: уровень 2 собирает
  `мама`, `мыла`, `раму`, уровень 3 — `мама мыла раму`, и фраза узнаётся;
* нисходящее воспроизведение в записанном порядке;
* реципрокное торможение «С»/«Ц» и ворота моторного выхода;
* побитовая воспроизводимость прогона при одном зерне топологии.

## Ограничения

* Один проход текста почти ничего не запоминает: нижним уровням нужно
  повторение. Поэтому `demo` предъявляет текст несколько раз
  (`--epochs`, по умолчанию 24).
* Цикл консолидации: `250 мс × L` — 250, 500, 750, 1000 мс для уровней
  1–4 и 1250…2250 мс для 5–9. Такт Инстинкта при этом остаётся 250 мс.
* Кадр записи верхнего уровня живёт один цикл от первого сигнала: слово
  и фраза звучат дольше одного такта.
* Без предустановленных слогов уровень 1 учит и перекрывающиеся пары
  («ам» из «мама»), поэтому на уровне 2 слово может собраться не тем.
  Предустановка канонических слогов задаёт словарь и снимает эту
  неоднозначность.
* Память не имеет забывания: ёмкость уровня ограничена числом ФИМ, после
  насыщения новые паттерны этого уровня не записываются.
* Параллельное воспроизведение всех активных очагов (как в ТЗ) даёт
  смешанный поток: латерального торможения в архитектуре нет, поэтому
  одновременно играют все задетые памяти. Для читаемого результата
  `ZIIS.recall(..., prefer_level=1)` воспроизводит самый полный активный ФИМ
  нужного уровня, а каскад от верхнего уровня и общий залп выводятся
  отдельными строками демо.
